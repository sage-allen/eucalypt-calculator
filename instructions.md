# Terminal Calculator

**These are basic instructions and guidance for this app to be created**

Guidance:
* create a terminal based application (suitable for windows and linux)
* it should be a close copy of speedcrunch (open source calculator application) however it should run entirely within terminal
* you should draw inspiration from the git interface tool ziggity in terms of styling
* it should have only the bare basics funcitonality. e.g. able to do bimdas, trig functions, pi, sqrt, modulo etc
* it should be programmed in rust following rust best practice
* the user should be able to assign variables i.e. x = 54
* the format of numbers should be 132,312.23123 for ease of readability
* it should be called Eucalypt Calculator and called in terminal by eucalypt
* on the start screen it should have an ascii picture of a eucalyptus tree with its leaves waving in the wind
